Guia de Utilização do Git

Nome: Francisco Miguel Santos | Turma: 10º28 | Nº: 06

Principais Comandos:

  • git init - Inicializar repositório
  • git clone - Clonar repositório
  • git status - Verificar o estado
  • git add . - Adicionar ficheiros
  • git commit -m "Mensagem" - Gravar alterações
  • git push - Enviar para o GitHub
